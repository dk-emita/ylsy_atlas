## Windows paketi — 13 Kasım 2026

Windows kurulum paketi, uygulamanın açılmamasına ve beyaz ekrana yol açan Qt/ICU kütüphane çakışmasının düzeltmesini içerir. Pencere ve görev çubuğu ikonu aynı onaylı görseli kullanır; kurulum kısayolları çalışan uygulamayla aynı kimliğe sahiptir.

Paketlenmiş EXE'de gerçek kontrol paneli, menüler, JavaScript, CSS ve yerel API yüklenmesi doğrulanmıştır.
